# The Worst Pizza Topping

One funny line pitching a terrible pizza topping:

> Try our canned tuna and jelly pizza: it jiggles, it smells like a harbour, and the jelly insists it's dessert.

110 characters. The pitch sells a genuinely awful combination — canned tuna and jelly — with three concrete beats: it jiggles, it smells like a harbour, and the jelly insists it's dessert. The final turn is the joke: the jelly has the confidence of a dessert while sitting on a fish pizza. It names the pizza and the topping, stays one sentence, and reads like a waiter proudly presenting the special.

## How to run

```sh
python3 main.py
```

This writes the line verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout. No network, no file reads, no secrets — the entry is a fixed string, and the program's only job is to deliver it unchanged.
